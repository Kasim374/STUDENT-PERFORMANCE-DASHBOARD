# Sales & Customer Intelligence Dashboard (Power BI)

##  Dashboard Overview
This Power BI project transforms raw retail transaction data into an interactive intelligence hub. It provides an end-to-end view of business health, combining descriptive analytics (what happened) with diagnostic and predictive insights (why it happened and what’s next).

##  Key Features
* **Executive KPI Summary**: Instant visibility into Total Revenue (**$844.02K**), transaction volumes, and average order values.
* **Customer Segmentation**: Dynamic classification of customers into **High-Value**, **Standard**, and **Basic** tiers based on purchasing behavior.
* **Regional Performance Matrix**: Interactive map and bar visuals identifying the **East Region** as the primary revenue driver ($194.45K).
* **Trend Intelligence**: Time-series analysis showing seasonal peaks (January) and monthly fluctuations.

##  Data Engineering & Modeling
* **ETL Process**: Data was cleaned and transformed using **Power Query**, including date normalization and helper column creation for customer initials and tenure.
* **DAX Measures**: Implemented custom DAX for dynamic calculations, including:
    * Total Sales & YTD Performance.
    * Customer Ranking and Categorization.
    * Regional Contribution Percentages.
* **Statistical Foundation**: Integrated findings from **Linear Regression** (Multiple R: 0.45) to validate trend lines and forecasting accuracy.

##  Repository Contents
* `Sales and Customer Intelligence Dashboard.pbix`: The complete Power BI file including data model, DAX measures, and report pages.
* `data/`: Source CSV files used for the analysis (Raw Data, Sales Analysis).

##  Business Insights
1.  **Revenue Concentration**: 75% of total revenue is generated by the Electronics category, suggesting a specialized market focus.
2.  **Loyalty Impact**: "High-Value" customers represent a critical segment for retention strategies and targeted marketing spend.
3.  **Payment Optimization**: Credit Card and PayPal are the leading payment methods, indicating a preference for digital-first transaction channels.

##  How to View
1.  Download the `.pbix` file from this repository.
2.  Open it using **Power BI Desktop**.
3.  Interact with the **Slicers** (Region, Category, Date) to explore the data dynamically.
